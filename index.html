What is value betting?

A value bet exists when the bookmaker's implied probability is lower than the true probability of an event occurring. If our model calculates a 50% true probability but the bookie prices it at 40% (odds of 2.50), we have a +10% edge. Over enough bets, positive expected value means profit.

Edge % = (Model probability − Bookie implied probability) × 100
Example: Model says 55% true prob. Bookie odds 2.20 → implied 45.5%. Edge = 55 − 45.5 = +9.5%

Data signals the model uses

  • Season batting average & strike rate — current IPL season weighted more heavily than career
  • Last N innings form — rolling 5-game window with exponential decay on older games
  • Phase-of-innings data — powerplay (ov 1–6), middle (7–15), death (16–20) performance split
  • Head-to-head vs opposition bowling — specific matchups vs pace, spin, left-arm etc.
  • Venue history — player's record at this specific ground
  • Pitch & conditions report — batting/bowling surface, toss result, dew factor
  • Team lineup & batting position — position determines balls faced expectation
  • Opposition bowling attack quality — economy rate, wicket-taking frequency
  • Injury & availability — playing XI confirmed or uncertain
  • Fatigue index — days since last game, travel schedule

Edge thresholds

  • +15% or higher — Strong value. High confidence pick.
  • +8% to +14% — Mild value. Worth tracking.
  • 0% to +7% — No significant edge. Bookie roughly fair.
  • Negative — Bookie underpricing. Avoid this market.

Adding your own data

Every market in the scanner has a bookieOdds and modelOdds field. To connect real data, replace those values with API calls to Cricsheet, CricAPI, or ESPNcricinfo. See the Data Guide tab for full field reference.

Wiring in real data (pseudocode)

// 1. Fetch live odds
const oddsResp = await fetch('https://api.the-odds-api.com/v4/sports/cricket_ipl/odds/?...');
const bookieOdds = parseOdds(oddsResp);

// 2. Fetch player stats from CricAPI
const statsResp = await fetch('https://cricapi.com/api/playerStats?pid=PLAYER_ID&apikey=...');
const stats = buildStatsObject(statsResp);

// 3. Run your probability model
const trueProbability = myModel.predict({ stats, venue, pitch, h2h });
const modelOdds = 1 / trueProbability;

// 4. Inject into market object
market.bookieOdds = bookieOdds;
market.modelOdds  = modelOdds;
market.stats      = stats;

// 5. Re-render — edge calculates automatically
renderMarkets();
